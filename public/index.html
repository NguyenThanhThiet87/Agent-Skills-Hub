Connect AI Agents (MCP Server Configuration)

Add this entry into your agent's mcp_config.json to let Antigravity, Claude Code, Cursor, or Windsurf discover and read skills automatically from this database: 

{
  "mcpServers": {
    "agent-skill-hub": {
      "command": "node",
      "args": ["D:/AgentSkillHub/server/mcp/mcpBridge.js"],
      "env": {
        "SKILLS_DIR": "D:/AgentSkillHub/skills"
      }
    }
  }
}
Exposed MCP Tools:
• list_skills(category?): Discovers skills and frontmatter from DB.
• get_skill(name): Reads markdown runbook and parameters schema.
• search_skills(query): Fuzzy matches skills by task intent.
